## این پروژه چیست؟

یک فریم‌ورک چندایجنت تجاری و **مستقل** — وابسته به هیچ سرویس یا فریم‌ورک بیرونی نیست. تمام قابلیت‌ها به‌عنوان **پلاگین داخلی** پیاده‌سازی میشوند (الگوی DeepSeek Harness).

**اصول کلیدی:**
- **کدبیس واحد:** یک دیتابیس، یک session log، یک حافظه، یک حلقه‌ی ایجنت
- **ماژولار از روز اول:** افزودن قابلیت جدید = یک پوشه‌ی جدید + یک مانیفست، **بدون بازنویسی کدهای موجود**
- **Adaptive Canvas UI:** چت ساده در پیش‌فرض؛ ابزارها فقط زمانی که نیاز میشوند ظاهر میشوند (۳ سطح: کارت درون‌خطی / پنل زنده / استیج کامل)
- **خودتکامل:** یادگیری از تعامل کاربر، بهینه‌سازی پرامپت، تولید خودکار اسکیل، خودترمیمی
- **چندپلتفرم:** وب، دسکتاپ (Tauri)، Hugging Face Space، ModelScope Studio
